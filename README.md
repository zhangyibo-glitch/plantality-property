# 植物人格图像生成器

桌面浏览器应用：上传真实植物照片，输入六项 HEXACO 数值，生成与参考图一致的植物人格画像，并导出 2048 × 2048 PNG。

## 使用方法

1. 双击 `打开应用.bat`。它会启动一个仅供本机访问的小型服务并打开默认浏览器。
2. 上传 PNG、JPG 或 WebP 植物照片。
3. 选择“AI 自动抠图”或“保留原图”。
4. 输入六项 HEXACO 数值，并调整主体透明度、晕色重叠和点染密度。
5. 点击“生成并导出 PNG”。

## 抠图说明

- AI 自动抠图在浏览器本地运行，照片不会上传服务器。
- 首次使用会下载约 40 MB 的量化模型，之后会使用浏览器缓存。
- 网络或浏览器不支持 AI 模型时，应用会自动切换到本地边缘抠图。
- 复杂背景可优先使用 AI 自动抠图；背景本身有价值时可选择保留原图。

## 运行环境

- 仅为桌面浏览器设计，建议窗口宽度不低于 1180 px。
- 推荐最新版 Chrome 或 Edge。启动器会自动提供 AI 抠图所需的浏览器性能设置。
- 除首次下载抠图模型外，其余图像处理和导出均在本地完成。
