# 식물 성격 이미지 생성기

식물 사진과 HEXACO 6요인 점수로 **식물 성격 이미지**를 만들어 2560 × 2560 PNG로 내보내는
데스크톱 브라우저 앱입니다. 사진의 윤곽을 따라 점묘가 흩어지고, 그 위에 HEXACO 레이더
차트가 얹힌 이미지가 만들어집니다.

설치가 필요 없고, 사진은 **이 컴퓨터 밖으로 나가지 않습니다.**

## 실행

`앱 실행.bat`을 더블 클릭하면 됩니다. 이 컴퓨터에서만 접근할 수 있는 로컬 서버가 뜨고
기본 브라우저가 열립니다. 2시간 동안 요청이 없으면 서버는 스스로 종료됩니다.

- 폴더는 아무 데나 풀어도 됩니다. 경로는 전부 폴더 기준으로 잡습니다.
- `index.html`을 더블 클릭해 여는 방식은 피하세요. AI 배경 제거 기능이 동작하지 않습니다.
- 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"으로 진행하세요.

## 사용 순서

1. **사진 업로드** — 업로드 칸이 두 개입니다.
   - *바깥 꽃*: 점묘의 **모양(윤곽)** 을 결정합니다. 여기 올린 사진의 실루엣을 따라 점이 몰립니다.
   - *안쪽 꽃*: 중앙에 겹쳐 그려지는 사진입니다. 비워두면 그리지 않습니다.
   - 한 장만 쓸 거라면 바깥 꽃 칸에만 올리면 됩니다.
2. **배경 처리 선택** — "AI 자동 배경 제거"(기본) 또는 "원본 유지".
3. **HEXACO 점수 입력** — 1.00 ~ 7.00. 4.00 이상이면 high, 미만이면 low로 라벨이 붙습니다.
4. **합성 조절** — 오른쪽 패널의 세 탭에서 레이어별로 조절합니다(아래 참고).
5. **PNG 생성 및 내보내기** — 2560 × 2560 PNG가 다운로드됩니다.

사진을 올리지 않아도 그리드와 HEXACO 육각형만 있는 **기본 이미지**가 그려져 있고, 그 상태로도
내보낼 수 있습니다. "초기화"를 누르면 사진과 설정이 모두 지워지고 이 상태로 돌아갑니다.

## 합성 조절 (오른쪽 패널)

### 이미지 1 · 바깥 꽃
사진의 윤곽을 추출해 가장자리를 따라 점을 뿌리는 레이어입니다.

| 항목 | 설명 |
| --- | --- |
| 원본 이미지 투명도 | 사진 자체의 표시 농도. **0으로 두면 점묘만 남습니다.** |
| 실루엣 크기 | 점묘와 사진의 전체 크기 |
| 회전 | 실루엣과 사진을 함께 회전 |
| 점 밀도 | 점의 개수 |
| 퍼짐 | 윤곽에서 점 구름이 뻗어나가는 거리 |
| 번짐 | 점 하나의 크기와 진하기 |
| 테마 색상 | 점 색상. 기본은 업로드한 사진에서 자동 추출 |

### 이미지 2 · 안쪽 꽃
중앙에 겹쳐 그려지는 사진입니다. **안쪽 꽃 사진을 따로 올렸을 때만** 나타납니다.

| 항목 | 설명 |
| --- | --- |
| 사진 투명도 | 0으로 두면 숨겨집니다 |
| 사진 크기 / 회전 | 중앙 사진의 크기와 각도 |
| 색조 | 컬러 그대로 두거나, 명암만 남기고 한 색으로(모노톤) |
| 모노톤 색상 | 테마 색상을 따르거나 직접 선택 |
| 질감 필터 | *점묘*는 바깥 점묘와 같은 점으로 사진을 다시 그려 질감을 맞춥니다. *거친 입자*는 사진을 알갱이로 부숩니다. |
| 필터 강도 | 필터의 세기 |

### HEXACO 그래프

| 항목 | 설명 |
| --- | --- |
| 그래프 크기 / 선 굵기 / 영역 채움 | 레이더 차트의 형태 |
| Subscale 라벨 | 6요인 각각의 **서브스케일 이름과 high/low 단어를 직접 입력**합니다. 그래프에는 `Dependence: low(independent)` 형식으로 표시됩니다. |
| 숫자 색상 | 점수 숫자의 색. 테마 색상을 따르거나 직접 선택 |

### 캔버스 여백
탭 아래에 있으며 모든 레이어에 함께 적용됩니다. 사진과 그래프를 안쪽으로 물려 점이 흩어질
자리를 만듭니다. 점 구름 가장자리가 각지게 잘려 보이면 이 값을 올리세요.

## 사진 처리와 개인정보

- 모든 이미지 처리와 내보내기는 **브라우저 안에서** 이루어집니다. 사진은 서버로 전송되지 않습니다.
- AI 자동 배경 제거는 처음 사용할 때 약 40 MB의 모델을 내려받고, 이후에는 브라우저 캐시를 씁니다.
  이때만 인터넷이 필요합니다.
- 모델을 받을 수 없으면 내장 윤곽 감지 방식으로 자동 전환됩니다. 이 경우 배경이 복잡한 사진은
  결과가 거칠어질 수 있습니다.
- 같은 점수와 같은 색이면 점묘 배치도 같습니다. 렌더 결과는 무작위가 아니라 재현됩니다.

## 실행 환경

- **Windows 전용**입니다(PowerShell 기반 로컬 서버).
- 최신 Chrome 또는 Edge를 권장합니다.
- 데스크톱 전용이며 창 너비 1180 px 이상이 필요합니다.

- `brand-spec.md` — 디자인 규격
